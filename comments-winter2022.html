  4. If you could give one piece of advice to someone taking this course in the future, what would it be?
    • Give yourself plenty of time to work on the projects. It'll take about 3-5x longer than you think it will, even if you're confident going into it. There are a lot of moving parts! 
    • I would highly recommend taking this course as it is a good representation of backend development and Object-Oriented Programming. I would advise to make sure that the other courses that are taken alongside this class aren't programming intensive.
    • Give yourself more time on the project and the material. Try your best to optimize/refactor it.
    • Really lean into Test Driven Development and exception handling from the beginning. It's easy to avoid them because they are unfamiliar to a lot of people, but they become more and more important as the assignments become more complex, and I think it's a lot easier to make the transition to these new paradigms in the earlier assignments.
    • I would advise them to do the Koans early.  It was really good practice to get into the Java mindset by implementing small lines of code at a time.  It also has stuff about resources later in the Koans that was helpful for projects (resources were talked about in the reflection screencast after the Koans due date).
    • Brush up on Java before the class since it can be challenging if you aren't already familiar with the language.
    • The one piece of advice for someone taking this course would be- Be prepared to code a lot for projects and make sure you don't take it with heavy courses like algorithms. This is because this course requires you to give a lot of time and attention. You will learn a lot but it requires you to be patient as well as devote a lot of time to the coursework. So be mentally prepared to write a lot of code as well as solve a lot of good questions and projects.
    • Get started on projects early because you'll probably have questions and I'm sure everyone prefers it when questions are not last-minute.
    • Be prepared from day1. Work on project0. Some classes usually pick up steam around the 3rd or 4th week, but in this class we immediately started coding on the first day of classes.
    • This course is very helpful and need to be in list of your CS Selective. However, the learner needs to prepare more about OOP such as CS202 and need to practice more before taking this course.
    • Read all footnotes in assignment specs, and write down the following graded course objectives in one place: - Quizzes (and dates for each quiz) - One pair programming session (and dates for available sessions) - One mob programming session (and dates for available sessions) - 6 project assignments (and each due date) - Plans of Attack are due 3 days before each project assignment - Koans (and due date) - Final exam (and date/time)
    • If someone asks me for the advice, I would say this class is really heavy and be prepare if you want to get deeply in coding. 
    • Start Early! The projects took a lot of time for me.  If I had waited to do any of them until the last minute it would have been a complete disaster. 
    • Take time to read the sub notes in the project assignments. Also, plan out all the functionality of a program before trying to build it. Many times I would build a program to realize it was not exactly what was asked for. 
    • Ask question if you have one, don't just assume.
    • Students should study the screencasts assigned for each class before joining the class' activities
    • I could give them advice that you should spend a lot of time to study carefully the documents and be patient. 
    • David's pacing suggestions are overly optimistic. Try to finish the easier half of the Koans during the first week- this will help you with the earlier programming assignments. And search for online examples to supplement the official course materials- it's easier to learn how to do things (e.g. work with the SAX and DOM APIs for XML parsing) if you're exposed to different examples outside of lecture.
